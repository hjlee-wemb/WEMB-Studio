# 스마트 산단 디지털 트윈 — 에셋 라이브러리 등록 목록

스튜디오 '에셋 라이브러리'에 산단 9화면의 컴포넌트를 올린다. 탭은 차트 · 심볼 · 아이콘 · 패널 · 이벤트 패널이다.
결과물은 `src/indpark-assets.js`(window.`__INDPARK_ASSETS`) 하나다. **손으로 고치지 말고 다시 돌린다.**

지금 목록(2026-11-13): 차트 4 · 패널 17 · 이벤트 8 · 심볼 56 · 아이콘 19.

| 파일 | 하는 일 |
|---|---|
| `spec.json` | 등록 목록. 컴포넌트는 `{sc, nid, name, fig}`(sc = main · menu · site · forklift · vibration · heat · event · history · sensor), 아이콘은 `[파일, 이름, Figma 이름]` |
| `measure.js` | Playwright filename. 미리보기(`src/indpark/<장면>.html?live=0`)에서 노드를 찾아 크기를 잰다 → `src/indpark/_gen/asset-sizes.json`. 서버는 `node src/indpark/_gen/serve.js 5560`, 실행은 `node src/indpark/_gen/pw.js` |
| `mk-assets.js` | spec + 크기 → `src/indpark-assets.js`. 같은 노드 두 번 · 이름 중복 · 다른 시안과 이름 겹침 · 파일 사용 여부(img · 인라인 svg data-src · CSS url)를 검사한다 |
| `patch-library.js` | 처음 연결할 때 한 번 돌린다(layout-editor.js `IP` · authoring.css `.hj-asset.ipX-root` · studio.html · tpl-modules.js ?v). 이미 적용했다 |
| `lib-check.js` | 탭마다 이 시안 것만 남겨 다크 · 라이트로 찍는다. **카드 바탕을 자홍으로** 칠해 투명이 아닌 곳이 바로 보인다 |
| `drop-check.js` | 패널 · 심볼 · 아이콘을 화면으로 끌어 넣어 본다 |

순서는 `measure.js` → `node src/indpark-assets/_gen/mk-assets.js` → `lib-check.js` · `drop-check.js` 이다. 목록을 바꾸면 **measure 부터 다시** 돌리고(크기는 목록 순번으로 묶인다) studio.html 의 `src/indpark-assets.js?v=` 를 올린다.

검증(2026-11-13):
- 다크 · 라이트 모두 깨진 그림 0 · 빈 칸 0 · 불투명 바탕 0이다(자홍 바탕이 그대로 비친다).
- 끌어 넣은 사본에 글자가 그대로 있고 바탕이 투명하다. 콘솔 오류는 0이다.

## 밟은 함정

- **아이콘 탭은 이름에 '아이콘'이 있어야 보인다**(layout-editor.js `isIconNamed`). 화살표 · 표시등 · 로고 칩 이름에 붙였다.
- **이름 겹침:** '접기 아이콘'이 한진 · 공장 전력설비와 겹쳐 '이벤트 로그 접기 아이콘'으로 바꿨다. 공통 부품에는 `(스마트 산단)`을 붙였다.
- **인라인 svg:** 상태 표시등은 img 가 아니라 인라인 svg(`data-src`)라, 처음엔 '화면이 안 쓰는 파일'로 걸렸다.
- **가는 띠는 빼다:** 팝업 · 패널 제목 띠(1036×59 · 1872×43, 상자 없는 묶음)는 카드 폭에 맞추면 1~4px 로 줄어 비어 보였다. 띠는 팝업 · 패널 안에 들어 있어 목록에서 뺐다.
- **흰 아이콘:** 라이트 테마 사본 `-lt.svg` 가 있으면 그것을 쓰고, 없으면 `-lib.svg`(명도만 뒤집음)를 만든다. check · 닫기가 해당한다.
