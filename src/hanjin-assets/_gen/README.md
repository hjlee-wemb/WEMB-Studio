## 등록 단위는 '컴포넌트'

눈금선·막대 한 줄·배지 그림자 같은 **부품은 등록하지 않는다.** 꺼내 쓸 수 있는 최소 단위는
위젯·차트·칩·단계 배지처럼 **그 자체로 뜻이 서는 덩어리**다.

| 탭 | 무엇 | 개수 |
| --- | --- | --- |
| 차트 | 도넛·게이지·미터·막대차트·가로막대·나침반 | 6 |
| 심볼 | 맵 액션·차량 필터·시점 프리셋·미니맵·도크 그룹·단계 배지 12 | 21 |
| 아이콘 | 화면이 쓰는 원본 SVG 파일(경로만 참조) | 22 |
| 패널 | 위젯 카드 15장(허브 인접 차량 목록 · 입/출문 현황 · 도크 상세현황 …) | 15 |
| 이벤트 패널 | 이벤트 현황 판과 그 부분(머리글·카운트·표·행·등급 배지 5·Auto 토글·접기 버튼) | 14 |

## 왜 Figma 내보내기가 아니라 화면 DOM 에서 뽑나

이천 FMS(`src/icheon-assets`)는 Figma 프레임을 SVG 로 내보내 파일로 두었다. 여기서는 그 방법을 쓰지 않았다.

1. **잘려서 나온다.** 이 시안의 `Event Log`(이벤트 현황)는 화면 프레임 밖으로 269px 나가 있는
   서랍형 판이라, `download_assets` 도 `get_screenshot` 도 **보이는 61px 만** 준다(1841x62).
   컴포넌트 정의는 라이브러리에 게시돼 있지 않아 `search_design_system` 으로도 못 찾는다.
2. **재구축본이 더 낫다.** `src/hanjin-*.js` 의 화면 DOM 에는 같은 컴포넌트가 온전히 들어 있고,
   글자가 **편집 가능한 실제 텍스트**다. 그래서 라이브러리에서 꺼낸 뒤에도 '패널편집'으로 글자를 고치고,
   화면 테마(다크/라이트)와 '색 정하기'가 썸네일까지 똑같이 따라온다. SVG 내보내기는 글자가 path 로 굳는다.

그래서 `src/hanjin-assets.js` 는 **마크업도 CSS 도 복사해 두지 않는다.**

- 마크업: 등록 목록에 `px`(화면)와 `nid`(Figma 노드 id)만 적고, 라이브러리가 `build_hjc/hjg/hju` 가 만든
  DOM 에서 `data-node-id` 로 서브트리를 잘라 쓴다(여는/닫는 태그 짝 세기, 화면당 한 번만 만들고 캐시).
- CSS: `window.HJC_CSS` 등 이미 로드된 시트를 스튜디오와 **같은 `style#hjX-style` id** 로 한 번만 붙인다.
  `.hjX-root` 안으로 스코프돼 있어 라이브러리 밖으로 새지 않는다.

덕분에 등록 목록은 12KB 뿐이다(마크업을 담았다면 450KB, CSS 까지면 1.2MB).

## 라이브러리 쪽에서 하는 일 (index.html)

- `hjDom(it)` — `<div class="hjX-root hj-asset" data-theme="…" style="width/height">` 로 감싸 그린다.
  `.hj-asset.hjX-root` 는 화면 뿌리가 갖는 '화면 전체를 덮는' 성질(absolute·inset·배경)만 끈다 →
  **썸네일 바탕은 투명**하고 컴포넌트 자신의 면색만 보인다.
- `.hj-asset > *` — 컴포넌트 뿌리는 화면 좌표에 절대배치돼 있으므로 그 자리 지정만 푼다(속은 그대로).
- `hjFit()` — 썸네일 배율. 보통은 통째로 보이게 맞추고(fit), 이벤트 머리글(1800x28)처럼 상자와 비율이
  2.6배 넘게 어긋나는 것만 채워서 왼쪽부터 자른다(cover). 자를 때는 상자 정렬도 `flex-start` 로 바꾼다 —
  가운데 정렬로 두면 원본 폭의 절반이 상자 밖에 있어 빈 곳만 보인다.
- `hjEmbedFit()` — 패널에 넣은 뒤에는 **폭**을 `zoom` 으로 맞춘다. `transform` 은 레이아웃 상자를 그대로 둬서
  1840px 짜리 판을 넣으면 슬롯이 그만큼 넓어져 패널 밖으로 삐져나간다. 높이는 그 뒤 스튜디오의 기존
  맞춤(`__wembFitAsset`, FIT_H=104)이 이어받는다.
- '패널' 카테고리라도 `it.dom` 인 것은 새 카드 컨테이너(`addPanelItem`)로 세우지 않고 패널 **안**에 넣는다.
  카드 컨테이너는 '빈 프레임'을 뜻하는데, 한진 위젯은 이미 완성된 판이라 프레임이 없다.

## 이벤트 패널 탭

이벤트 현황 판은 부분마다 따로 쓰인다(머리글만, 표만, 등급 배지만). 그래서 판 전체와 함께
그 안의 덩어리들을 같은 탭에 등록했다. 이천 FMS 의 **이벤트 목록**도 패널 탭에서 이리로 옮겼다
(판별 기준은 이름에 '이벤트'가 들어가는지 — `isEventNamed`).

## 이름 짓기

화면에 찍힌 한글을 그대로 쓴다(`허브 인접 차량 목록`, `요일별 하차물량`, `단계 하차완료` …).
Figma 레이어명과 노드 id 는 `fig` 에 남겨 두어 되짚을 수 있게 했다.

## 함정

- **노드 id 가 화면 DOM 과 다를 수 있다.** 변형 세트(`data-hj-vset`)를 펼친 자리는 conv.js 가 변형 노드의
  id 를 쓴다 — `Fold Button(65:826)` → `65:3129`, `Floor Selector(65:645)` → 층별 변형 5개.
  후자는 부모인 `View Presets(65:644)` 로 등록했다.
- **`Event Log` 인스턴스(65:817)는 DOM 에 없다.** 껍데기가 접히고 속 프레임 `65:818` 이 그 자리를 쓴다.
  크기(1840x330)도 nodes JSON 에 없어 등록 목록에 직접 적었다.
