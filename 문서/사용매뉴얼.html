WEMB Studio

화면설계, 이제
고객과 함께 즉석에서

비개발자도 최신 트렌드로 관제 화면 컨셉을 몇 분 만에 잡고, 레퍼런스와 자산을 조합해 고객과 실시간으로 설계·제안하는 도구예요.

01

WEMB Studio가
추구하는 것

더 빠르게, 더 적은 공수로, 고객과 함께 좋은 화면을 설계하는 것.

시간 절약 · 공수 최소화

손이 많이 가던 화면 시안 작업을, 고르고 조합하는 방식으로 짧게 끝내요.

최신 트렌드 선제안

요즘 감각의 레퍼런스와 팔레트를 먼저 제시해, 고객이 고르기만 하면 되게 해요.

고객과 함께 설계

회의 자리에서 바로 바꿔 보여주며, 대화하는 과정에서 니즈를 함께 다듬어요.

비개발자를 위한 ‘바이브 디자인’

코드를 몰라도 감각적으로, 디자이너처럼 화면을 만들어 볼 수 있어요.

다양한 경험 제공

화면 종류·레이아웃·라이트/다크·시각 강도까지, 여러 안을 빠르게 경험하게 해요.

자산의 라이브러리화

WEMB의 시각 자산을 구조·속성·관계로 정형화해 JSON으로 변환하고, 재사용 컴포넌트로 축적해요. 한 번 만든 자산이 다음 제안에서 다시 쓰이며 점점 빨라져요.

02

실제로
무엇을 해주나

기능을 외울 필요 없이, 이 도구는 세 가지 일을 잘하도록 만들어졌어요.

핵심 01

빠른 컨셉 초안

화면 종류·레이아웃을 고르고 색을 얹으면, 몇 분 만에 보여줄 컨셉 초안이 나와요. 백지에서 시작하지 않아요.

화면 종류레이아웃컨셉 색
핵심 02

트렌드 선제안

고객의 니즈를 듣고 최신 트렌드를 바로 접목해 먼저 제안해요. 요청받기 전에 방향을 제시하죠.

추천 테마라이트/다크시각 강도
핵심 03

레퍼런스·자산 조합

다양한 레퍼런스와 자산을 보여주고 조합해 가며 고객의 진짜 니즈를 도출해요. 대화가 곧 설계가 됩니다.

자산 라이브러리A/B 비교공유
03

딱 두 화면만
알면 됩니다

작업을 고르는 런처에서 시작해, 실제로 설계하는 스튜디오로 들어가요.

제작 파이프라인
1 PRD› 2 기능명세서› 3 유저플로우› 4 와이어프레임› 5 스튜디오

PRD에서 니즈를 질문으로 받으면 뒤 단계가 자동으로 만들어지고, 그 구성이 스튜디오에 그대로 반영돼요. 스튜디오가 실제 화면을 디자인하는 핵심 단계예요.

프로젝트 런처 · 시작 지점

고객사·시안별로 작업을 폴더처럼 관리해요.

  • 전체 · 최근 · 즐겨찾기 · 휴지통 — 작업 목록을 상태별로.
  • 새 프로젝트 — PRD 질문으로 니즈를 받아 초안 생성.
  • 검색 — 프로젝트 이름으로 바로 찾기.
스튜디오 · 작업 공간

왼쪽 도구로 조작하고, 오른쪽 실제 화면에서 결과를 즉시 확인해요.

  • 좌측 레일 — 화면 정하기 · 색 정하기 · 접근성 검증 · 저장 · 내보내기.
  • 상단 바 — 되돌리기 · 내보내기 · 공유, 그리고 파이프라인 탭.
  • 미리보기 — 설계가 실시간 반영되는 진짜 대시보드.
04

처음이라면,
이 3단계

런처에서 제안까지 실제로 밟는 순서예요.

STEP 1

프로젝트 시작

런처에서 새 프로젝트를 만들거나, 목록의 기존 작업을 열어요. 하던 작업은 최근 편집에서 이어가고요.

STEP 2

니즈 입력 → 자동 초안

PRD 질문에 한 단계씩 답하면 기능명세서·유저플로우·와이어프레임이 자동 생성되고, 그 구성이 스튜디오에 반영돼요.

STEP 3

스튜디오에서 마감 · 제안

좌측 레일에서 색·구성을 다듬고, 오른쪽 미리보기로 확인한 뒤 공유·내보내기로 고객에게 제안·전달해요.

프로젝트 런처

작업 관리 · 새 프로젝트 · 검색

  • 전체 / 최근 편집 — 전체 목록과 최근 손댄 순. 이어서 작업할 땐 최근 편집.
  • 즐겨찾기 / 휴지통 — 별표 모아보기, 삭제 항목 복원·영구삭제.
  • 새 프로젝트 / 검색 / 템플릿 — 새 프로젝트는 PRD 질문으로, 템플릿은 준비 중.
주의

휴지통의 영구삭제는 되돌릴 수 없어요. 지우기 전에 대상이 맞는지 확인하세요.

제작 파이프라인 · 상단 탭

PRD → … → 스튜디오

  • PRD — “무엇을 만들지” 질문에 답하며 고객 니즈를 정리. 여기 답이 뒤로 이어져요.
  • 기능명세서 · 유저플로우 · 와이어프레임 — PRD 기반 자동 생성(일부 준비 중).
  • 스튜디오 — 색·레이아웃·내용을 실제 화면에 입혀 완성·제안하는 핵심 단계.
스튜디오 좌측 레일 · 5가지 도구

화면 정하기 · 색 정하기 · 접근성 · 저장 · 내보내기

  • 화면 정하기 — 화면 형식(대시보드·디지털 트윈·포탈) · 버전(Flat·Enterprise) · 라이트/다크.
  • 색 정하기 — 기준색(직접·사진 추출·추천·로고·기본값) · 배색 · 팔레트 · 미세조정.
  • 접근성 검증 — WCAG 대비비 표 + 자동으로 통과 수준 보정.
  • 저장 · 스냅샷 — 시안 저장 · 되돌리기 기록 · A/B 비교.
  • 내보내기 — CSS · JSON · Figma · Tailwind · 이미지 · 공유 URL.
규칙

미세조정은 기준 색에만 적용되고, 결과는 오른쪽 미리보기에만 반영돼요(좌측 메뉴 색은 고정).

상단 바 · 미리보기

전역 도구와 살아 있는 화면

  • 되돌리기 · 다시 실행 · 공유 — 직전 작업 취소·재적용, 상태를 담은 링크 공유.
  • 전체 기본값으로 되돌리기 — 색·구성·기록을 처음 상태로(저장한 스냅샷은 유지).
  • 실시간 미리보기 — 시계·날씨·KPI 카운트업·차트 애니메이션으로 진짜 운영 화면처럼.
참고 · 색 역할 토큰

값만 바꾸면 화면 전체가 바뀌는 이유

색을 화면에 직접 칠하지 않고 역할 이름(토큰)에 연결하기 때문이에요. 내보내면 아래 토큰으로 정리돼 나와요.

  • point-main / point-sub — 주·보조 포인트 색
  • bg-page / bg-surface — 페이지 · 카드 배경
  • text-strong / text-weak — 강조 · 약한 텍스트
  • line · warning · danger — 구분선 · 경고 · 위험 상태색
  • radius-panel — 모서리 둥글기
06

자주 묻는
질문

먼저 알아두면 좋은 것들.

그래서 이 솔루션은 한마디로 뭔가요?
화면설계 디자인 솔루션이에요. 비개발자도 최신 트렌드로 화면 컨셉을 빠르게 잡고, 레퍼런스·자산을 조합해 고객과 함께 실시간으로 설계·제안합니다. 색·검증·내보내기는 그 설계를 완성하는 수단이고요.
설치나 로그인이 필요한가요?
아니요. 브라우저에서 주소만 열면 됩니다. 서버 없이 동작하는 단일 웹앱이라 배포·이식이 간단해요.
PRD·기능명세서 단계는 꼭 거쳐야 하나요?
PRD는 니즈를 정리하고 뒤 단계를 자동 생성하기 위한 출발점이에요. 스튜디오가 실제 화면을 디자인하는 핵심 단계이며, 중간 단계는 앞 단계를 마치면 열려요(일부 준비 중).
작업한 내용은 어디에 저장되나요?
차트 종류·시안 스냅샷은 사용하는 브라우저 안에 저장돼요. 다른 사람과 나눌 땐 공유 URL이나 내보내기를 쓰세요.
미리보기 숫자는 실제 데이터인가요?
현재 지표는 시뮬레이션 데이터예요. 설계가 실제 화면에서 어떻게 보이는지 확인하는 용도이며, 실데이터 연동은 향후 과제입니다.
‘자산 라이브러리’는 무슨 뜻인가요?
WEMB의 시각 자산을 구조·속성·관계로 정형화해 JSON으로 변환하고 재사용 컴포넌트로 축적한다는 뜻이에요. 한 번 만든 자산이 다음 제안에서 다시 쓰이며 작업이 점점 빨라집니다.
