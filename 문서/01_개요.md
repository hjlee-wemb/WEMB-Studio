## 1.1 프로젝트 개요

**WEMB Studio**는 컬러 테마를 생성·검증·관리하고, 그 결과를 **관제 대시보드·디지털 트윈** 등 실제 운영 화면에 즉시 반영해 미리보기할 수 있는 **웹 기반 테마 저작(Authoring) 도구**이다.

프로젝트 단위로 작업을 관리하는 **런처(프로젝트 목록)** 에서 시작해, 구성할 **화면 종류(대시보드 / 디지털 트윈 / 포탈)** 와 **레이아웃**을 고른 뒤 스튜디오로 진입하는 흐름을 갖는다. 포인트 색상 변경만으로 전체 테마가 일관되게 전환되도록 표준화하고, 색 전문 지식이 없는 사용자(고객사 운영자·기획자)도 접근성(WCAG) 기준을 충족하는 테마를 만들어 CSS/JSON/Figma/Tailwind 토큰과 개발자 핸드오프 자산으로 산출할 수 있도록 하는 것이 목적이다.

## 1.2 추진 배경

- 기존 관제 대시보드 디자인(Figma `system` 파일, key `1fIpWV8TozxhsKD5qIX35D`)은 색상이 화면 곳곳에 하드코딩되어, 테마 변경 시 수작업 비용이 컸다.
- 색상을 **디자인 토큰(변수)** 으로 추상화하여, 포인트 색 하나로 테마 전체를 제어할 수 있는 구조가 필요했다.
- 대시보드뿐 아니라 **디지털 트윈·포탈 등 화면 유형이 늘어나면서**, 화면 종류·레이아웃별로 일관된 테마를 적용하고 결과를 미리 확인할 수 있는 통합 저작 환경이 요구되었다.
- 여러 고객사·시안을 다루기 위한 **프로젝트 단위 관리(생성·검색·즐겨찾기·휴지통)** 의 필요성이 대두되었다.
- 비개발 실무자도 **접근성 기준을 자동으로 만족**하는 테마를 스스로 구성·산출할 수 있는 셀프서비스 도구에 대한 요구가 있었다.
- 참고 서비스: BairesDev *AI Colors*(색 기반 테마 전환), Pantone *올해의 컬러 2026 (Cloud Dancer)*.

## 1.4 주요 기능 요약

1. **프로젝트 런처** — 전체·최근 편집·즐겨찾기·휴지통(복원/영구삭제)·템플릿(준비 중) 뷰, 검색, 새 프로젝트 만들기
2. **화면 구성** — 화면 종류(대시보드 / 디지털 트윈 / 포탈(준비 중)) 및 레이아웃 선택 후 스튜디오 진입
3. **레이아웃** — 대시보드 2단/3단/모듈, 디지털 트윈 2·3·4레벨(각 행 변형) — Figma `Studio` 파일 구조를 그대로 반영
4. **테마 생성** — 기준 색(Seed)·배색 방식(Harmony)·이미지 추출·랜덤·올해의 트렌드 컬러
5. **접근성 검증** — WCAG 대비비 자동 계산, AAA 필터링, 미달 자동 보정
6. **테마 관리** — 스냅샷 저장·버전 히스토리·되돌리기, A/B 비교 뷰
7. **산출(Export)** — CSS 변수 / JSON 토큰 / Figma 변수 / Tailwind config / PNG·SVG / 공유 URL / 개발자 핸드오프
8. **화면 저작** — 카드 배치·내용·차트 종류·디자인(모서리 등) 편집, 디지털 트윈은 3D 씬 위 유리 패널 배치
9. **고객사 브랜드** — 브랜드명·로고 등 고객사 정보 반영
10. **시각 체계** — Flat(≤10색) / Enterprise(≤50색) 토글
11. **실시간 요소** — 실시간 시계·날씨, KPI 카운트업, 차트 애니메이션
12. **라이트/다크 모드** — 설정 패널·콘텐츠·팝업 통합 동기화

## 1.5 대상 사용자

| 사용자 | 활용 목적 |
|---|---|
| 고객사 운영자 | 프로젝트별로 관제 대시보드·디지털 트윈 테마를 직접 선택·적용하여 운영 환경에 반영 |
| 내부 기획자 / PM | 설계서 근거(대비비 표·토큰)로 테마를 정의하고 시안·산출물 확보 |
| 개발자 | 산출된 CSS/JSON/Figma/Tailwind 토큰과 핸드오프 자산을 실제 구현에 연계 |

## 1.6 기대 효과

- 테마 변경 리드타임 단축(수작업 색상 교체 → 토큰 기반 일괄 전환)
- 접근성 기준(WCAG) 위반 리스크 사전 차단
- 디자인–개발 간 토큰 표준화 및 **핸드오프 자산 제공으로 핸드오프 비용 절감**
- 프로젝트·화면 종류·레이아웃 단위 재사용으로 다중 고객사 대응 효율화
- 고객사 셀프서비스로 커스터마이징 대응 부담 완화
