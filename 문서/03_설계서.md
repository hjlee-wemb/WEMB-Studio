## 3.1 화면 설계

### 3.1.1 전체 레이아웃
- **상단 바**: 제작 파이프라인 탭(PRD · 기능명세서 · 유저플로우 · 와이어프레임 · 스튜디오) + 되돌리기/다시 실행 · 내보내기 · 공유
- **좌측 레일**: 아이콘형 도구 전환(스튜디오 홈 · 테마 만들기 · 대시보드 편집 · 되돌리기 기록) → 5도구 패널(화면 정하기 · 색 정하기 · 접근성 검증 · 저장·스냅샷 · 내보내기)
- **우측 미리보기**: 반응형 관제 대시보드/디지털 트윈(100vh), 상단 로고·실시간 시계·날짜/날씨
- 폰트: Pretendard (CDN), 최소 12px

### 3.1.2 프로젝트 런처
- 좌측 목록 탭(전체 · 최근 편집 · 즐겨찾기 · 휴지통 · 템플릿), 새 프로젝트 만들기 카드, 검색
- 새 프로젝트 → **PRD 위저드**("무엇을 만들지 알려주세요", 단계별 질문/1·6) → 기능명세서 자동 생성

### 3.1.3 스튜디오 좌측 레일 도구
| 도구 | 세부 |
|---|---|
| 화면 정하기 | 화면 형식(대시보드/디지털 트윈/포탈) · 버전(Flat/Enterprise) · 화면 테마(라이트/다크) · 레이아웃 |
| 색 정하기 | 기준 색(직접색·사진 추출·추천 적용·로고에서 추출·기본값) · 배색 방식 · 현재 팔레트(칩) · 미세조정(H/S/L) |
| 접근성 검증 | 대비비 표 · AAA 필터 · 자동으로 고치기 · 변경 내역 |
| 저장·스냅샷 | 스냅샷 저장/불러오기 · 되돌리기 기록(타임라인) · A/B 비교 |
| 내보내기 | CSS/JSON/Figma/Tailwind · 대시보드 PNG · 팔레트 SVG · 공유 URL · 디자인 사양서(PDF) · 화면 전체 HTML · 컴포넌트별 코드 |

### 3.1.4 대시보드 편집 · 에셋 라이브러리
- 콘텐츠 추가: ＋패널 / 패널편집
- 에셋 라이브러리: 에셋 검색 + 탭(차트 · 심볼 · 아이콘 · 패널), 항목을 **끌어다(드래그) 화면에 삽입**
- 차트 에셋: KPI 지표 · 누적 막대 · 표 · 게이지 · 라인 · 가로 막대 · 불릿 · 간트 · 도넛 · 히트맵 · 스파크라인 등
- 빈 패널에는 "에셋을 끌어 넣어 주세요" 안내

### 3.1.5 상호작용 규칙
- 활성 소스 외 입력 방식은 **disable** 처리(현재 무엇이 활성인지 명확히 표시)
- **미세조정은 기준 색에서만** 가능하며 **우측 콘텐츠에만 반영**(좌측 메뉴 색 고정)
- 이전 단계를 완료해야 다음 파이프라인 탭이 열림(잠금 툴팁 안내)
- 전체 초기화는 색·구성·기록을 되돌리되 저장한 스냅샷은 보존
- 표 hover 피드백, 편집 모드 시 텍스트 커서 신호 제공

## 3.2 테마 토큰 설계 (Design Tokens)

CSS 변수 기반으로 테마를 추상화하여, 토큰 값 교체만으로 전체 UI가 일괄 전환된다. (내보내기 CSS 예시 기준)

| 토큰 | 역할 |
|---|---|
| `--bg-page` | 페이지 배경 |
| `--bg-surface` | 카드/서피스 배경 |
| `--bg-accent` | 강조 배경 |
| `--point-main` | 주 포인트 색 |
| `--point-sub` | 보조 포인트 색 |
| `--text-strong` | 강조 텍스트 |
| `--text-weak` | 약한 텍스트 |
| `--line` | 구분선/보더 |
| `--warning` / `--danger` | 경고/위험 상태색 |
| `--radius-panel` | 모서리 둥글기 |
| `--font` | 폰트 패밀리 |

> 색은 HSL 기반으로 관리되며, 명도(L) 조정으로 대비비 보정을 수행한다.

## 3.3 기능 모듈 설계

### 3.3.0 제작 파이프라인 (Pipeline)
- PRD 위저드(질문 단계·진행 상태), 단계 잠금("이전 단계를 먼저 완료해 주세요")
- PRD → 기능명세서 자동 생성(→ 유저플로우 · 와이어프레임 · 스튜디오 반영) *(일부 준비 중)*

### 3.3.1 컬러 연산 (Color Math)
- `hexToRgb`, `rgbToHsl`, `hslToHex`, `hslToCss`, `clamp`, `normHex`

### 3.3.2 색 정하기 · 팔레트 생성 (Palette Generation)
- 기준 색 입력 방식: 직접색 · 사진 이미지 추출 · 추천 골라 적용 · 로고에서 기준색 · 기본값
- `genPalette` — 기준 색 + 배색 방식으로 팔레트 산출
- `buildDirect` / `computeHexMap` / `adjustHex` — 역할별 색 매핑 산출
- `applyAdjust` / `resetAdjust` — 미세조정(H/S/L) 적용·초기화

### 3.3.3 접근성 검증 (WCAG Engine)
- `relLum`(상대휘도) → `contrast` / `wcagRatio`(대비비) 계산
- `enforceAAA` / `enforceContrast` / `fixContrastLightness` — 미달 색을 통과 수준으로 명도 보정
- `contrastRows` / `renderContrast` / `fixThemeContrast` — 검증표 렌더 및 일괄 보정

### 3.3.4 Enterprise 시각 체계
- `genEnterprise` / `entCoreMap` — ≤50색 토큰 확장 생성
- `enhanceEnterpriseBars` — 증감률 표시·그라데이션 테두리·은은한 배경 애니메이션 등 고급 시각 처리

### 3.3.5 대시보드 렌더 (Charts / Widgets)
- 차트: `makeThroughput`(라인), `makeConnected`, `makeCircuit`, `makeDonut`, `makeHeat`
- 렌더러: `renderAxis`, `renderDonut`, `renderGauge`, `renderHeat`, `renderProgress`, `renderTable`, `genericRender`
- `spline` 등 곡선 보간, 진입 애니메이션(`intro`)

### 3.3.6 콘텐츠 저작 · 에셋 라이브러리 (Authoring)
- 배치: `applyLayout` / `setLayout` (2단/3단/모듈, 디지털 트윈 2·3·4레벨)
- 내용/차트 종류: `setContent`, `saveTypes` / `loadTypes`, `recommend`(제목 기반 추천)
- 에셋 라이브러리: 검색(`libsearch`), 탭(차트/심볼/아이콘/패널), 라이브러리 아이템(`.libitem`) 드래그 삽입, 빈 패널(`.emptybody`/`.emptyhint`)
- 디자인: `applyRadius`, `syncVersionUI`
- 하위 메뉴: `openSub` / `hideSubs` / `openMenu` / `buildPicker`

### 3.3.7 실시간 요소
- `fmtClock`(시계), `loadWeather` / `initWeather`(날씨 — Open-Meteo API + 브라우저 Geolocation, 위치 거부 시 서울 폴백)
- `liveKPI` / `animateVal` / `tick` — KPI 카운트업 주기 갱신

### 3.3.8 저장·스냅샷 · 히스토리 · A/B
- 히스토리: `captureTheme`, `restoreTheme`, `themeSig`, `commitHistory`, `renderHistory`, `jumpHistory`
- 스냅샷: `loadSnapshots` / `saveSnapshots` / `addSnapshot` / `deleteSnapshot` / `renderSnapshots`
- A/B 비교: `abThemeList`, `refreshABOptions`, `namespaceIds`, `renderThemeInto`, `renderAB`, `openAB`

### 3.3.9 내보내기 (Export)
- 토큰: `genCSS`, `genJSON`, `genFigma`, `genTailwind`
- 이미지: `exportPNG`(대시보드 PNG), `genPaletteSVG`, `exportSVG`(팔레트 SVG)
- 핸드오프: 디자인 사양서(PDF), 화면 전체 HTML, 컴포넌트별 코드 복사
- 공유: `encodeState` / `decodeState` / `shareURL` / `copyShare` / `applyShareFromURL`

### 3.3.10 컴포넌트 시트 (State Gallery)
- 화면 사용 컴포넌트 + 미노출 추정 컴포넌트/상태값 열람, 상태 히트맵, HTML 내보내기(`csExport`)

## 3.4 상태 관리 설계

| 상태 | 저장 위치 |
|---|---|
| 콘텐츠 차트/데이터 종류 | localStorage (`saveTypes`/`loadTypes`) |

## 3.5 주요 화면 요소(ID/클래스) 참고
- 파이프라인 탭: `.tb-tab`(PRD/기능명세서/유저플로우/와이어프레임/스튜디오), PRD 위저드 `.prdwiz-x` / `.pw-btn` / `.snav-next`·`.snav-prev`
- 런처: `.lc-navi`(전체/최근/즐겨찾기/휴지통/템플릿), `.lc-cardnew`(새 프로젝트 만들기)
- 화면 정하기: 화면 형식 · 버전(Flat/Enterprise) · 화면 테마 · `.resetall`(전체 기본값으로 되돌리기)
- 색 정하기: 기준색 방식(`.ghostbtn`) · 배색 · 팔레트(칩) · 미세조정 `adjH`/`adjS`/`adjL`/`adjReset`
- 대시보드 편집: `.addpanel`, `.libsearch-wrap`, `.libitem`(차트/심볼/아이콘/패널), `.emptyhint`
- 대비비 검증: `ctModal` / `ctTable` / `ctFix` / `ctFixBar` / `ctChanges`
- A/B 비교: `abModal` / `abSelA` / `abSelB` / `abPrevA` / `abPrevB`
- Export: `exModal` / `exTabs` / `exCode` / `exPng` / `exSvg` / `exShare`
- 컴포넌트 시트: `csModal` / `csSheet` / `csExport`
