### 변경 이력 (Changelog)

WEMB Studio의 버전별 변경 사항을 기록합니다.
버전 체계는 [유의적 버전(SemVer)](https://semver.org/lang/ko/)의 개발 단계(`0.y.z`)를 따르며, 각 버전에 릴리스 날짜를 병기합니다.

- `0.MINOR` : 의미 있는 기능 묶음 추가
- `0.0.PATCH` : 버그 수정·소규모 개선
- `1.0.0` : 첫 안정(정식) 릴리스 예정

#### [Unreleased] — 2026-10-12 고객사 현장용(P0)

### 추가

- 프로젝트 파일 — 프로젝트를 화면 · 작업 상태째 `.wemb.json` 하나로 저장(홈 프로젝트 카드 · 프로젝트 안 '파일로 저장', 작업공간 내보내기 '프로젝트 파일 저장'), 홈 '파일 열기'(끌어 놓기도)로 다른 PC 에서 이어서 작업
- 발표 모드(`present.html`) — 도구를 숨기고 시안만 크게, ←/→ 화면 넘기기(다음 화면은 뒤에서 미리 열어 0.2~0.7초), F 전체 화면, M 회의 모드, Esc 로 들어온 화면에 복귀. 작업공간 상단 바 · 홈 프로젝트 카드에서 시작. 발표 중에는 작업 상태를 바꾸지 않는다
- 회의 모드 — 화면의 고객사 이름(POSCO · LS Electric · SK하이닉스 · 한진 · HANA 등)을 '고객사'로 가려 보여 줌(원본은 그대로, 고치는 중엔 안 가림). 템플릿 갤러리는 '회의용 고르기'로 고른 것만, 제목 대신 '화면 유형 · 업무 영역'
- 인터넷 없이 쓰기 — `WEMB Studio 켜기.cmd`(로컬 서버, 포트 5510). 글꼴 · 3D 를 로컬 사본(`src/vendor`)으로, 날씨는 마지막 값 · 예시 값
  - Node.js 와 `wemb-atomic` 폴더가 있으면 wemb-atomic 서버로 켜서 분자 라이브러리 · 원자 변경까지 된다. 없으면 설치 없는 PowerShell 서버로 켜고(그 두 기능만 빠짐) 켜기 창에 이유를 보여 준다

### 개선

- 화면 전체 HTML — 화면에 쓰인 그림 · 글꼴을 파일 안에 담아 다른 PC · 인터넷 없이도 그대로 열린다. 스튜디오에서 보던 크기 그대로 창에 맞춰 줄이고 늘린다(템플릿 아래 기본 화면이 비치던 문제 해결)
- 공유 링크를 '색 테마 링크'로 바로잡음 — 색 테마만 담긴다는 걸 단추 · 안내에 적었다(예전 안내는 '같은 시안이 그대로'라고 했다)
- 사용 매뉴얼 단추가 로컬 문서를 연다
- 템플릿 헤더의 로고 · BI(RENOBIT · SK하이닉스 BI · 예전 'WEMB Studio' 표시)를 모두 WEMB Studio 로고(`src/studio-logo.svg`)로 보여 준다(`js/templates/image.js` TPLLOGO, 원래 시안 파일은 그대로)
  - DOM 템플릿(POSCO · LS Electric · HANA · 한진 · SK하이닉스 팝업 · Icheon main)은 헤더 로고 묶음 자리에 로고 그림을, 헤더가 밝아지는 라이트 테마에선 짙은 판(`studio-logo-lt.svg`)을. SK하이닉스 1level(인라인 SVG)은 로고 그룹 자리에
  - 그림 템플릿은 88장 중 로고가 있는 87장의 로고 자리를 재 둔 표(BOX)로 — 원래 로고를 둘레 배경으로 메우고 그 위에 얹는다. 로고가 원래 바탕보다 밝았으면 흰 로고, 어두웠으면 짙은 로고
  - '로고 업로드 → 로고에서 기준색'으로 올린 로고가 있으면 그 로고가 우선하고, '기본값'이면 WEMB Studio 로고로 돌아간다. 예전엔 그림 템플릿의 로고 자리를 자동으로 찾아 날짜 · 제목을 로고로 덮기도 했다
- 분자 라이브러리 · 원자 변경의 '서버에 연결하지 못했어요' 안내가 켜기 파일로 여는 방법을 알려 준다
- wemb-atomic 서버가 `::1`(IPv6)에도 열린다 — `localhost` 로 열 때 첫 연결마다 0.3초(브라우저) · 2초(PowerShell) 기다리던 것이 없어졌다

### 수정

- 프로젝트 안에서 템플릿 갤러리로 넘어가면 폴더 이름 · 경로 표시 · 점선 테두리가 남던 문제
- 한진 템플릿 미리보기(갤러리 카드 · 상세 3장 · 프로젝트 썸네일)가 DOM 재구축 전 그림(옛 HANJIN 로고 · 옛 화면)이던 것을 스튜디오에 연결된 실제 화면 캡처(1920x1080)로 바꿈

#### [Unreleased] — 2026-09-11 (refactor/pages)

### 추가

- 화면마다 주소 — 홈 `#/projects` · `#/projects/:gid` · `#/templates/:slug` …, 작업공간 `#/prd` ~ `#/studio`. 새로고침 · 뒤로가기 · 링크 공유가 같은 화면으로 돌아온다(`js/core/router.js`)
- 작업공간 문서 `studio.html` — `?screen=<id>` 로 화면을 연다. 앱이 뜨기 전에 그 화면의 상태 묶음으로 맞춘다(`js/app/session.js`)

### 개선

- 단일 `index.html`(2.5MB · 34k줄)을 홈 `index.html`(약 9KB)과 작업공간 `studio.html`, 그리고 `css/` · `js/` 기능별 파일로 분리
- 홈은 스튜디오 DOM · 템플릿 화면 스크립트(약 12MB)를 받지 않는다
- 런처 코드(`flow.js` 2천 줄)를 공용 저장소(`js/core/projects.js`) · 레이아웃(`js/core/layouts.js`) · 템플릿 카탈로그 · 홈 화면 · 작업공간 화면 진입으로 분리
- 흩어져 있던 런처 · 토스트 · 포커스 링 스타일을 제자리 파일로(`css/launcher` · `css/base`)
- 공유 링크 형식 `#/studio?t=…` (예전 `#t=…` 링크도 그대로 열린다)

### 수정

- 파일 분리 직후 디지털 트윈 배경 사진과 Tomorrow 폰트가 404 — CSS 상대 경로를 스타일시트 위치 기준으로
- 런처 뒤로 버튼에 핸들러가 두 벌 붙어 한 번 누르면 둘 다 돌던 문제

### 제거

- 들어갈 경로가 없던 새 프로젝트 모달 · 레이아웃 선택 UI(새 프로젝트는 PRD 로 시작한다)

#### [0.10.0] — 2026-08-21

### 추가

- SK하이닉스 이천 FMS 디지털 트윈 화면 — Figma export 기반 인라인 SVG(래스터 배경 + 벡터 레이어, `skx-` 네임스페이스)를 대시보드 화면 종류에 편입(`src/skhynix-screen.js`)

- 화면 라이브 인터랙션 — 실시간 시계, 티커 메시지 마퀴(심리스 루프), 경보 아이콘 맥동·확산 링, 센서 심볼 호버, 이벤트 목록 데이터 테이블 주입
- 이벤트 목록 패널 확장/축소 — 하단 expand 버튼으로 패널 슬라이드업·다운(클립 해제) + 화살표로 상태 표시
- 'Auto' 라디오 버튼 — 클릭 시 선택/해제(링 강조 + 중앙 도트) 토글
- 배치 모드 패널 드래그 이동 — SK하이닉스 화면 패널을 좌표 그룹으로 묶어 끌어 이동, 위치 로컬 저장(`wemb-skx-panelpos`)
- 사용 매뉴얼 — 빠른 사용 흐름 안내서(`문서/사용매뉴얼.html`)와 메뉴·옵션 전체 상세 매뉴얼(`문서/사용매뉴얼_상세.html`, PDF)
- 제품 문서 정비 — 개요·요구사항·설계서·아키텍처 문서(`문서/01~04`)

### 개선

- 차트 에셋 3종(UPS 전력량·센터 온도·상면 포화도) 카드 배경/테두리(rect) 제거 → 그래프·라벨·미터 콘텐츠만 노출(라이브러리 에셋 한정, `.fig-svg` 스코프)
- 이벤트 expand 화살표 회전을 360° 누적 → 열림·닫힘 180° 토글로 변경(상태 가독성 향상)

### 수정

- 이벤트 expand 버튼에 클릭 핸들러가 중복 바인딩되어 화살표가 이중 회전하고 버튼 전체가 뒤집히던 문제 → 단일 핸들러(클래스 토글)로 정리, 데이터 주입·z-order만 잔여 로직으로 분리
