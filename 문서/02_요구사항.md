## 2.3 제약 사항 (Constraints)

- 단일 `index.html` 파일 구조 유지 (Vanilla JS, 외부 빌드 도구 미사용)
- 백엔드 없음 — 상태는 브라우저(localStorage) 및 공유 URL로만 관리
- 날씨 등 외부 데이터는 클라이언트에서 직접 호출
- 관제 지표는 시뮬레이션 데이터 기반 (실데이터 연동은 범위 외)
- 파이프라인 일부 단계(기능명세서·유저플로우·와이어프레임)는 자동 생성 기반으로 준비 중

## 2.4 요구사항 이력 관점

요구사항은 초기 컬러 테마 저작에서 **화면설계 디자인 솔루션**으로 확장되며 상세화되었고, 다음 항목이 강화·신설되었다.
- 포지셔닝 확장: 컬러 테마 도구 → 화면설계 솔루션(PRD 파이프라인·에셋 라이브러리·트렌드 선제안)
- 프로젝트 런처 및 새 프로젝트(PRD) 흐름 도입
- 색 정하기 입력 방식 확장(직접색 → 사진 추출·로고 추출·추천 적용·기본값)
- 대시보드 저작에 에셋 라이브러리(드래그 삽입) 도입
- 내보내기 확장(PDF 사양서·화면 전체 HTML·컴포넌트별 코드)
- 접근성 자동 보정, 시각 체계 이원화(Flat/Enterprise), 미세조정 반영 범위 제어, 라이트 모드 완성도는 지속 유지·개선
