## 개요

WEMB Studio의 **화면 제작 시작 경험을 '프로젝트 단위의 단계별 흐름'으로 재설계**함. 기존에는 도구를 열면 곧바로 편집 화면이 나왔지만, 이제 **프로젝트 홈에서 시작해 → 새 프로젝트를 만들고 → 구성할 화면 종류(대시보드·디지털 트윈·포탈)를 고른 뒤 → 그에 맞는 화면 틀을 선택**하면 미리보기에 바로 반영되는 순서로 흐름을 정리함. 아울러 **좌측 작업 메뉴를 더 단순하게 정리**하고 **홈에서 프로젝트를 직접 관리(삭제)** 할 수 있게 하여, 시작부터 정리까지의 사용 경험을 매끄럽게 다듬음.

## 핵심 기능 요약

- **프로젝트 홈:** 만든 프로젝트를 한눈에 보고 새로 만들거나 삭제하는 시작 화면
- **단계별 만들기:** 새 프로젝트 → 화면 종류 → 화면 틀 순서로 따라가며 화면 구성
- **화면 종류 선택:** 대시보드·디지털 트윈·포탈 중 목적에 맞게 선택
- **화면 틀 선택·반영:** 여러 화면 틀을 골라 미리보기에 바로 적용
- **간편한 좌측 메뉴:** 화면 틀을 카테고리별로 접었다 펴며 손쉽게 선택

## 기술 구성

- **설치 없이 바로 사용:** 브라우저에서 바로 열리는 하나의 화면으로 제작
- **선택 내용 유지:** 만든 프로젝트와 고른 화면 틀이 자동 저장되어 다시 열어도 그대로 유지
- **색상 자동 연동:** 어떤 화면 틀을 골라도 정한 색 테마를 그대로 따라감
- **화면 크기 자동 대응:** 창 크기에 맞춰 내용이 자연스럽게 맞춰짐
- **원본 보존:** 기존 버전은 그대로 두고 새 화면에서 작업해 안전하게 시험

## 이슈 & 해결

- 화면 틀을 고른 뒤 화면 구성 메뉴를 조작하면 내용이 사라지는 문제 → 원인을 찾아 내용이 유지되도록 수정
- 좌측 메뉴가 딱딱한 선택창처럼 보임 → 기존 화면 선택 메뉴와 같은 방식으로 통일해 자연스럽게 개선
- 모듈형 화면 틀이 다른 종류와 구조가 겹침 → 디자인 원본을 다시 확인해 서로 구분되는 배치로 정리
- 디자인 원본 접근이 일시적으로 제한됨 → 다른 연결 경로로 우회해 필요한 화면 틀을 정상적으로 가져옴
