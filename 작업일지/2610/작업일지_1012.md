## 개요

기존 대시보드 디자인을 **누가 만들어도 같은 결과가 나오는 WEMB 디자인 시스템**으로 정리함. Microsoft·Apple·Google의 글로벌 디자인 키트를 기준으로 **디자인 토큰·컴포넌트·사용 가이드**를 한 파일에 구축하고, 화면설계서만 넣으면 이 규칙대로 화면을 만들어 주는 **AI 화면 자동 생성 스킬**을 제작·검증함. 이후 로고·심볼·명칭을 **WEMB 브랜드로 일원화**하고, 개발팀이 바로 쓸 수 있도록 **사용 안내서와 배포본**을 구성함.

## 주요 작업 내역

| 구분              | 작업 내용                                                                                     | 상태 |
| ----------------- | --------------------------------------------------------------------------------------------- | ---- |
| 자료 분석         | 기존 대시보드 디자인 파일과 글로벌 디자인 키트(Apple · Microsoft · Google)의 구성 파악          | 완료 |
| 디자인 토큰       | 색·간격·모서리·선 두께·글자 기준값 194개, 글자 스타일 20종, 그림자 4종 정리                    | 완료 |
| 컴포넌트          | 화면에서 찾은 부품 49종(변형 포함 162개)을 재사용 컴포넌트로 제작하고 상태 이름 통일           | 완료 |
| 사용 가이드       | 시작 안내·자료 목록·토큰표·컴포넌트 모음과 부품별 가이드 15페이지를 Microsoft 형식으로 구성   | 완료 |
| 화면 예시         | 기존 화면 1장을 컴포넌트만으로 다시 조립한 예시 작성                                           | 완료 |
| 글꼴 통일         | 공식 글꼴을 Pretendard로 정하고 문서·기준값 전체에 반영                                        | 완료 |
| AI 화면 자동 생성 | 설계서를 넣으면 같은 규칙으로 화면을 만드는 AI 스킬 제작 (명세표 → 조립 → 점검 → 보고)        | 완료 |
| 시험 검증         | 예시 설계서로 '운영관리 › 이력조회' 화면을 만들어 규칙 위반 0건 확인                           | 완료 |
| 브랜드 적용       | 로고·심볼을 WEMB로 교체하고, 문구·기준값 이름을 WEMB로 통일                                    | 완료 |
| 개발팀 전달       | 사용 안내서, 설치 파일, 팀 공용 보관용 폴더 구성                                               | 완료 |

## 핵심 기능 요약

- **한 곳에서 관리하는 디자인 기준:** 색·간격·글자를 이름 붙은 기준값으로 관리해, 한 번 바꾸면 모든 화면에 함께 반영
- **바로 가져다 쓰는 부품:** 패널·표·카드·버튼 등 49종을 상태별로 준비
- **보고 따라 하는 가이드:** 부품마다 쓰임새·구성·사용 규칙을 한 페이지에 정리
- **설계서만 넣으면 화면 완성:** AI가 설계서를 읽고 같은 규칙으로 화면을 조립
- **스스로 하는 점검:** 기준에서 벗어난 색·글자를 자동으로 찾아 0건이 될 때까지 확인
- **WEMB 브랜드 일원화:** 로고·심볼·명칭을 WEMB로 통일

## 기술 구성

- **하나의 디자인 파일:** Figma 한 파일에 기준값·부품·가이드·화면 예시를 함께 보관
- **AI 작업 지시서:** 작업 순서와 규칙, 참고 자료, 조립 도구를 하나로 묶은 Claude 스킬
- **두 가지 결과물:** Figma 화면과 웹 화면을 같은 기준값으로 제작
- **공식 글꼴:** Pretendard
- **간단한 전달:** 설치 파일 하나와 사용 안내서로 바로 사용

## 이슈 & 해결

- AI 도구가 Pretendard 글꼴을 불러오지 못해 글자를 고칠 수 없던 문제 → 작업하는 동안만 임시 글꼴로 바꾸고 끝나면 Pretendard로 되돌리도록 절차를 정리
- 칸 폭이 바뀌면 KPI 카드가 줄바꿈되며 배치가 깨지던 문제 → 줄마다 폭을 나눠 채우는 방식으로 바꿔 어떤 폭에서도 유지
- 좁은 칸에 범례를 넣으면 패널 제목과 겹치던 문제 → 최소 폭을 정하고, 부족하면 자동으로 경고하도록 추가
- 표 칸의 글자가 두 줄로 넘어가던 문제 → 한 줄로 고정하고 넘치면 말줄임 처리
- 부품 변형을 복사하면 글자 연결이 끊기던 문제 → 연결을 다시 이어 모든 변형에서 글자 변경이 되도록 정리
- Figma와 웹의 기준값 이름이 일부 달랐던 문제 → 두 쪽 이름을 1:1로 맞춤
- 로고·심볼 데이터를 옮기며 오류가 생길 우려 → 원본 파일과 한 글자씩 대조해 검증한 뒤 반영
