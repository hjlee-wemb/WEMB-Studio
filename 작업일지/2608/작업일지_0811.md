## 개요

WEMB Studio에서 **디지털 트윈 화면 시안을 직접 편집**할 수 있도록 기능을 보강함. 화면에 놓인 패널을 **원하는 자리로 바꾸고 안의 글자·숫자를 직접 수정**할 수 있게 하고, 화면 크기와 상관없이 **여백과 간격이 일정하게 보이도록** 정리함. 또한 **패널 간격 조절을 별도 옵션으로 분리**하고, 주요 지표(KPI) 숫자가 잘리지 않고 **깔끔하게 보이도록** 개선함. 레이아웃 선택 메뉴도 **옵션이 한눈에 모두 보이도록** 정돈함.

## 핵심 기능 요약

- **패널 직접 편집:** 화면 속 패널을 원하는 자리로 옮기고, 안의 글자·숫자를 눌러 바로 수정
- **일정한 여백·간격:** 화면 크기가 달라도 패널 간격과 바깥 여백이 항상 균일하게 표시
- **자리 바꾸기 배치:** 패널을 옮겨도 전체 구성은 흐트러지지 않고 위치만 서로 교체
- **간격 옵션 분리:** 패널 간격을 따로 조절하되, 조절해도 패널 크기는 그대로 유지
- **지표 가독성:** 주요 지표 숫자가 잘리지 않고 여백 있게 깔끔히 표시

## 기술 구성

- **설치 없이 바로 사용:** 브라우저에서 바로 열리는 하나의 화면으로 제작
- **작업 내용 유지:** 바꾼 배치·내용이 자동 저장되어 새로고침해도 그대로 유지
- **화면 크기 자동 대응:** 창 크기에 맞춰 패널과 글자가 자연스럽게 맞춰짐
- **간단한 조작:** 마우스만으로 패널을 옮기고 글자를 수정

## 이슈 & 해결

- 패널 간격을 조절하면 패널 크기까지 같이 줄어들던 문제 → 간격만 조절되고 패널 크기는 유지되도록 분리
- 주요 지표(KPI) 숫자가 옆이 잘려 보이던 문제 → 칸마다 여백을 주고 칸 폭에 맞춰 자동으로 보이도록 수정
- 패널을 자유롭게 옮기면 서로 겹치거나 배치가 흐트러지던 문제 → 같은 크기 패널끼리 자리만 맞바꾸도록 개선
- 레이아웃 선택 목록이 중간에서 잘려 스크롤이 생기던 문제 → 옵션이 전부 한 번에 보이도록 정리
- 화면 크기에 따라 여백이 들쭉날쭉하던 문제 → 어느 화면에서도 여백·간격이 균일하게 보이도록 수정
