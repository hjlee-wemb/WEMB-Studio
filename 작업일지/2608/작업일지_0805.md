## 개요

WEMB Studio의 **프로젝트 생성 흐름을 단계별로 정리**함. 요구사항 작성(PRD)부터 기능명세서·화면 흐름도·와이어프레임·스튜디오까지 **순서대로 진행되도록** 하고, **각 단계를 마쳐야 다음으로 넘어가도록** 구성함. 특히 **화면 흐름도(유저플로우) 편집 기능을 크게 보강**하여, 항목을 검색·즐겨찾기하고 글자를 직접 수정하거나 세부 기능을 골라 추가할 수 있게 함. 화면 흐름도를 **확대·축소하고 자유롭게 이동**하며 편하게 살펴볼 수 있도록 정리함.

| 기능명세서 자동 생성    | 요구사항에 입력한 내용에 맞춰 기능 목록이 자동으로 만들어지도록 함                | 완료 |
| 기능명세서 필터         | 상단 필터로 요구사항·상태·역할·중요도별로 골라 볼 수 있게 함                      | 완료 |
| 다음 단계 이동 안내     | 기능명세서를 끝까지 확인한 뒤에 다음 단계 버튼이 나타나도록 함                    | 완료 |

| 화면 흐름도 직접 수정    | 각 항목의 글자를 눌러 바로 수정하고, 항목을 눌러 세부 기능을 골라 추가하도록 함  | 완료 |
| 화면 흐름도 확대·축소·이동 | 확대·축소 버튼과 단축키를 추가하고, 빈 곳을 끌거나 스페이스바로 화면을 이동하도록 함 | 완료 |
| 상단 로고·화면 정리      | 상단 로고를 누르면 홈으로 이동하고, 화면 흐름도 글자 크기를 화면에 맞게 조정      | 완료 |

## 핵심 기능 요약

- **단계별 진행:** 요구사항 → 기능명세서 → 화면 흐름도 → 와이어프레임 → 스튜디오를 순서대로 진행하고, 각 단계를 마쳐야 다음이 열림
- **요구사항 기반 자동 생성:** 입력한 요구사항에 맞춰 기능명세서가 자동으로 만들어지고, 필터로 원하는 항목만 골라 보기
- **화면 흐름도 편집:** 항목의 글자를 직접 수정하고, 필요한 세부 기능을 골라 추가
- **검색·즐겨찾기:** 원하는 항목을 검색해 확대해 보고, 즐겨찾기한 항목만 모아 보기
- **자유로운 화면 탐색:** 확대·축소와 화면 이동으로 큰 구성도 편하게 살펴보기

## 기술 구성

- **설치 없이 바로 사용:** 브라우저에서 바로 열리는 하나의 화면으로 제작
- **작업 내용 유지:** 입력·설정이 자동 저장되어 새로고침해도 작업하던 화면이 그대로 유지
- **화면 크기 자동 대응:** 창 크기에 맞춰 글자와 화면이 자연스럽게 맞춰짐
- **단계 잠금:** 앞 단계를 마쳐야 다음 단계가 열리도록 안전하게 구성
- **간단한 조작:** 마우스와 단축키만으로 확대·축소·이동을 손쉽게

## 이슈 & 해결

- 새로고침하면 처음 화면(스튜디오 홈)으로 돌아가던 문제 → 작업 중이던 화면이 그대로 유지되도록 수정
- 화면 흐름도 글자가 너무 크게 보이던 문제 → 화면 크기에 맞춰 자동으로 조정되도록 수정
- 항목을 옮길 때 색상까지 따라 바뀌던 문제 → 색상 배치는 그대로 두고 내용만 바뀌도록 수정
- 검색창과 확대·축소 버튼이 한쪽으로 치우쳐 있던 문제 → 가운데로 모으고 아이콘 형태로 깔끔하게 정리
