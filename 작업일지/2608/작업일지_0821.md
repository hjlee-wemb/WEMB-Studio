## 개요

WEMB Studio를 **처음 쓰는 사람도 혼자서 따라 할 수 있도록 사용 매뉴얼을 새로 작성**함. 큰 흐름을 빠르게 익히는 **안내서**와, 화면의 모든 메뉴·버튼을 하나씩 사전처럼 찾아볼 수 있는 **상세 매뉴얼**을 함께 만들고, 화면(웹)과 인쇄·공유용 **PDF** 두 가지 형태로 제공함. 이와 함께 SK하이닉스 디지털 트윈 화면에서 사용자가 직접 조작하는 부분(이벤트 목록 패널 열고 닫기, 버튼 화살표 상태 표시, '자동' 선택 버튼, 일부 차트 배경 정리)도 다듬음.

## 주요 작업 내역

| 구분             | 작업 내용                                                                                       | 상태 |
| ---------------- | ---------------------------------------------------------------------------------------------- | ---- |
| 사용 매뉴얼 작성 | 처음 쓰는 사람이 큰 흐름을 빠르게 익히는 **안내서** 작성 (준비 → 니즈 입력 → 자동 초안 → 마감·제안) | 완료 |
| 사용 매뉴얼 작성 | 화면의 모든 메뉴·버튼을 하나씩 설명한 **상세 매뉴얼** 작성 (사전처럼 찾아보는 용도)             | 완료 |
| 매뉴얼 배포 형태 | 매뉴얼을 화면(웹)과 인쇄·공유용 **PDF** 두 가지로 제공                                          | 완료 |
| 이벤트 패널 동작 | 하단 버튼을 누르면 이벤트 목록 패널이 위로 올라오고, 다시 누르면 내려가도록 정리                | 완료 |
| 버튼 화살표 표시 | 패널이 열리면 버튼 화살표가 방향을 바꿔 열림·닫힘 상태를 한눈에 알 수 있게 함                   | 완료 |
| 자동 선택 버튼   | '자동' 버튼을 라디오 버튼처럼 눌러 선택/해제하고, 선택하면 표시가 켜지도록 함                   | 완료 |
| 차트 배경 정리   | UPS 전력량·센터 온도·상면 포화도 차트에서 배경을 없애고 그래프 내용만 보이도록 함               | 완료 |

## 핵심 기능 요약

- **처음이어도 쉬운 안내서:** 준비부터 니즈 입력, 자동 초안, 마감·제안까지 실제로 밟는 순서를 그대로 따라 하도록 정리
- **사전처럼 찾는 상세 매뉴얼:** 화면 순서대로 각 메뉴·버튼의 이름·하는 일·옵션·팁을 모두 정리해, 필요한 항목만 바로 찾아볼 수 있음
- **어디서나 보는 문서:** 화면(웹)으로 바로 보고, 인쇄·공유가 필요하면 PDF로 사용
- **이벤트 목록 열고 닫기:** 하단 버튼 하나로 이벤트 목록을 올렸다 내렸다 함
- **상태를 알려주는 화살표:** 패널이 열리면 화살표 방향이 바뀌어 지금 상태를 바로 확인
- **자동 선택 버튼:** 라디오 버튼처럼 눌러서 켜고 끄기
- **깔끔한 차트:** 일부 차트에서 배경을 없애고 내용만 보이도록 정리

## 기술 구성

- **두 가지 매뉴얼:** 큰 흐름을 익히는 안내서와, 메뉴를 하나씩 설명하는 상세 매뉴얼로 나눠 제공
- **두 가지 형태:** 브라우저에서 바로 보는 화면과, 인쇄·공유용 PDF로 함께 제공
- **설치 없이 바로 사용:** 브라우저에서 바로 열리는 하나의 화면
- **부드러운 움직임:** 패널이 올라오고 화살표가 도는 동작이 자연스럽게 이어짐
- **간단한 조작:** 마우스 클릭만으로 열고 닫고 선택

## 이슈 & 해결

- 기능이 많아 처음 쓰는 사람이 어디서부터 시작할지 어려워하던 문제 → 큰 흐름 안내서와 항목별 상세 매뉴얼을 함께 제공해 상황에 맞게 골라 보도록 정리
- 매뉴얼을 화면으로만 봐서 인쇄·공유가 불편하던 부분 → 인쇄·공유용 PDF를 함께 제공
- 이벤트 패널 버튼을 누르면 동작이 두 번 겹쳐 화살표가 어색하게 움직이던 문제 → 하나의 동작으로 정리해 자연스럽게 열고 닫히도록 수정
- 화살표가 한 바퀴 돌아 열림·닫힘 구분이 애매하던 부분 → 상태에 맞춰 방향만 뒤집히도록 변경
- '자동' 버튼을 눌러도 선택 표시가 없던 부분 → 라디오 버튼처럼 선택하면 표시가 켜지도록 추가
- 일부 차트에 불필요한 배경이 함께 보이던 문제 → 배경을 없애고 내용만 깔끔하게 보이도록 정리
