## 개요

WEMB Studio를 **'고객사 맞춤 시안 제작 도구'로 확장**하는 데 집중함. 완성한 화면을 **화면 전체 또는 원하는 구성 요소(카드) 단위로 손쉽게 전달할 수 있는 기능**을 도입하고, 처음 쓰는 사람도 순서대로 따라갈 수 있도록 **화면 설정 → 색 지정 → 검증 → 저장 → 전달로 이어지는 단계별 안내 흐름**을 설계함. 아울러 새 버전에서 **고객사 로고·이름을 화면에 직접 반영하고, 카드를 추가·삭제하며 화면 구조를 자유롭게 구성**할 수 있도록 개선함. 안내·경고 요소의 배치와 시인성을 정비하고, 링크 공유 시 미리보기가 정상 노출되도록 정리함.

## 핵심 기능 요약

- **시안 전달:** 완성한 화면을 통째로, 또는 원하는 카드만 골라 손쉽게 복사·전달
- **단계별 안내:** 처음 쓰는 사람도 순서대로 따라가도록 화면이 하나씩 열리며 유도
- **브랜드 맞춤:** 로고와 이름을 넣어 '우리 회사 화면'처럼 보이도록 구성, 로고 색으로 팔레트 자동 생성
- **화면 자유 편집:** 카드 추가·삭제와 열 수 조절로 원하는 화면 구조를 직접 구성
- **안내 정돈:** 저장 위치 주의·색 대비 경고 등 꼭 필요한 안내를 눈에 잘 띄게 정리

## 기술 구성

- **단일 화면 구성:** 별도 설치 없이 브라우저에서 바로 열리는 하나의 화면으로 제작
- **브랜드 정보 유지:** 넣은 로고·이름이 자동 저장되어 다시 열어도 그대로 유지
- **색상 자동 연동:** 새로 추가한 카드도 기존 색상 테마를 그대로 따라가며 밝고 어두운 모드에 자동 대응
- **전달물 자동 정리:** 시안을 내보낼 때 편집용 버튼은 빠지고 실제 화면만 담기도록 처리
- **새 버전 분리 운영:** 기존 화면은 그대로 두고, 새 기능은 별도 버전으로 만들어 안전하게 검증

## 이슈 & 해결

- 색 지정 화면에서 다음 메뉴가 통째로 숨겨져 무엇이 있는지 알기 어려움 → 메뉴 구성은 보이되 옵션(값)만 순서대로 열리도록 변경
- 컴포넌트를 복사할 때 화면 요소가 눌려 조작되는 혼선 → 복사 중에는 화면 조작을 잠가 복사에만 집중하도록 처리
- 저장 위치 안내와 도움말 표시가 서로 떨어져 있어 산만함 → 한 묶음으로 가깝게 배치하고, 경고는 눈에 띄는 아이콘으로 정리
- 색 대비 경고 안내의 버튼·아이콘이 잘 보이지 않음 → 배경을 채우고 글자 대비를 높여 또렷하게 개선
- 링크 공유 시 미리보기 이미지가 뜨지 않음 → 공유용 이미지 주소를 정확히 지정해 정상 노출되도록 수정
