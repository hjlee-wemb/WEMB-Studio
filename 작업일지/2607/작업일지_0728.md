## 개요

WEMB Studio의 **화면 제작 경험을 '기획 관점의 단계별 흐름'으로 재설계**하는 데 집중함. 화면 틀부터 고르던 기존 방식 대신, **무엇을 위한 화면인지(목적)와 무엇을 보여줄지(핵심 정보)를 먼저 정하고 그에 맞는 화면 틀이 따라오는 순서**로 흐름을 정리함. 이를 뒷받침하기 위해 **디자인 원본의 표준 화면 틀 24종을 도구 안에서 바로 불러와 실제 운영 내용으로 미리보기**하는 방식을 만들어 검증하고, 검증 후에는 **기존 대시보드 화면을 기준 화면으로 안정화**함. 아울러 **고른 정보에 맞는 화면 틀을 자동으로 추천하는 방식**과 **고급형·기본형 화면의 차이를 뚜렷하게 하는 개선안**을 설계함.

## 핵심 기능 요약

- **단계별 화면 제작:** 목적 → 정보 → 화면 틀 → 마무리 순서로 따라가며 화면을 만드는 흐름
- **표준 화면 틀 활용:** 디자인 원본의 검증된 화면 틀을 골라 바로 화면에 반영
- **실제 내용 미리보기:** 실제 지표·그래프·표로 채워 완성된 모습에 가깝게 확인
- **똑똑한 틀 추천:** 보여줄 핵심 정보를 고르면 어울리는 화면 틀을 자동으로 추천
- **버전별 차이 강화:** 고급형과 기본형 화면을 한눈에 구분되게 정리

## 기술 구성

- **설치 없이 바로 사용:** 브라우저에서 바로 열리는 하나의 화면으로 제작
- **화면 크기 자동 대응:** 창 크기에 맞춰 내용이 자연스럽게 맞춰짐
- **색상 자동 연동:** 어떤 화면 틀을 골라도 정한 색 테마를 그대로 따라감
- **선택 내용 유지:** 고른 화면 종류·틀이 자동 저장되어 다시 열어도 그대로 유지
- **안전한 검증 운영:** 기존 화면은 그대로 두고 새 방식은 별도로 시험한 뒤 반영

## 이슈 & 해결

- 실제 내용이 화면 틀보다 커서 넘치거나 잘림 → 화면 틀을 원래 크기로 그린 뒤 화면에 맞게 전체를 함께 줄여 내용이 깔끔하게 담기도록 개선
- 화면 틀에 따라 그래프·표가 한쪽으로 치우쳐 단조로움 → 각 칸 크기에 맞는 내용을 자동으로 배치하도록 조정
- 기준 화면으로 되돌리는 과정에서 그래프·시계 등 일부가 표시되지 않음 → 원인을 찾아 정상 표시되도록 수정
- 디자인 원본 접근이 일시적으로 제한됨 → 다른 연결 경로로 우회해 필요한 화면 틀을 정상적으로 가져옴
