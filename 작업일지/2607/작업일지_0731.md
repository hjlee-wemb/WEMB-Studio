## 개요

WEMB Studio 화면을 **참고 UI를 바탕으로 한 새 버전으로 재구성**함. 화면 전체를 어둡고 현대적인 톤으로 다듬고, **위쪽에는 페이지를 오가는 상단 메뉴**를, **왼쪽에는 아이콘 메뉴**를 두어 구조를 정리함. 각 메뉴를 누르면 **그에 맞는 옵션만 보이도록** 정돈하고, **대시보드 편집 기능을 용도별로 나눠** 사용하기 쉽게 함. 기존 스튜디오 화면은 그대로 유지한 채, 그 위에 **여러 페이지(스튜디오·PRD·기능명세서·유저플로우·와이어프레임)를 오갈 수 있는 상단 메뉴를 더함**.

## 핵심 기능 요약

- **상단 페이지 메뉴:** 스튜디오와 여러 문서 페이지(PRD·기능명세서·유저플로우·와이어프레임)를 한 화면에서 오가며 확인
- **좌측 아이콘 메뉴:** 아이콘을 누르면 옆으로 메뉴가 펼쳐지고, 고른 메뉴에 맞는 옵션만 표시
- **용도별 대시보드 편집:** 화면 구성·콘텐츠 추가·배치와 내용·디자인을 나눠 필요한 부분만 손쉽게 편집
- **색 정하기 정리:** 로고에서 대표색을 뽑아 색을 정하고, 화면 형식은 따로 분리해 단계가 더 명확
- **깔끔한 새 화면:** 어둡고 정돈된 톤으로 다듬어 보기 편하고 현대적인 인상

## 기술 구성

- **설치 없이 바로 사용:** 브라우저에서 바로 열리는 하나의 화면으로 제작
- **한 화면에서 페이지 전환:** 창을 새로 열지 않고 화면 안에서 페이지를 오감
- **선택 내용 유지:** 정한 색과 설정이 자동 저장되어 다시 열어도 그대로 유지
- **화면 크기 자동 대응:** 창 크기에 맞춰 내용이 자연스럽게 맞춰짐
- **원본 보존:** 기존 버전은 그대로 두고 새 버전에서 안전하게 작업

## 이슈 & 해결

- 콘텐츠 패널을 추가해도 화면에 제대로 나오지 않던 문제 → 원인을 찾아 정상적으로 표시되도록 수정
- 새 프로젝트를 만들어도 이전 화면이 그대로 남던 문제 → 새로 시작할 때 처음 상태로 초기화되도록 수정
- 왼쪽 아이콘 메뉴가 눌러도 반응하지 않던 문제 → 원인을 찾아 정상 작동하도록 수정
- 스튜디오가 여러 페이지 중 하나처럼 묻혀 보이던 문제 → 스튜디오를 기본 화면으로 두고 상단 메뉴를 더하는 방식으로 정리
