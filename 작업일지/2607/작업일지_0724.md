## 개요

WEMB Studio에 **생산현황(Production) 대시보드를 신규 구축**하고, 상단 메뉴를 통해 종합현황과 오갈 수 있도록 연결함. 모든 차트에 **마우스를 올리면 상세 수치가 표시되는 기능**을 전 종류에 걸쳐 도입하고, 대시보드 편집에서 **차트 종류를 자유롭게 바꿀 수 있도록 선택 폭을 확대**(생산 전용 차트 유형 5종 추가)해 두 화면 모두에서 동일하게 동작하도록 통합함. 아울러 초기 설정 화면의 **작업 순서를 직관적으로 재배열**하고 카드 펼침·접힘에 **부드러운 전환 효과**를 적용했으며, 색상까지 완전히 초기화되지 않던 **전체 되돌리기 기능을 정상화**함.

## 핵심 기능 요약

- **생산현황 대시보드:** 제조 현장에서 쓰는 핵심 지표를 한 화면에 모아, 상단 메뉴로 종합현황과 오가며 볼 수 있도록 구성
- **수치 바로 보기:** 어떤 차트든 마우스를 올리면 해당 지점의 항목과 값이 말풍선으로 즉시 표시
- **차트 종류 바꾸기:** 편집 모드에서 각 칸의 표현 방식(막대·꺾은선·도넛·파레토 등)을 원하는 대로 선택할 수 있고, 생산 화면의 차트도 동일하게 지원
- **설정 화면 정리:** 가장 먼저 정해야 할 ‘화면 종류’를 첫 단계로 올리고, 카드가 펼쳐지고 접힐 때 부드럽게 움직이도록 개선
- **완전 초기화:** 되돌리기 한 번으로 색상을 포함한 모든 설정이 처음 상태로 복원

## 기술 구성

- **단일 화면 구성:** 별도 설치 없이 브라우저에서 바로 열리는 하나의 화면으로 제작
- **화면 공유 구조:** 종합현황과 생산현황이 상단 헤더·시계 등은 공유하고 본문만 교체되도록 구성해 이동이 매끄러움
- **색상 자동 연동:** 새로 만든 생산 화면의 모든 차트가 기존 색상 테마를 그대로 따라가도록 연결, 밝고 어두운 모드 모두 자동 대응
- **차트 통합 관리:** 두 화면의 차트를 하나의 방식으로 관리해 종류 변경·저장·초기화가 동일하게 동작
- **설정 자동 저장:** 사용자가 바꾼 화면과 차트 종류가 자동 저장되어 다시 열어도 그대로 유지

## 이슈 & 해결

- 전체 되돌리기를 눌러도 색상이 초기화되지 않음 → 색상 설정이 저장되는 항목이 초기화 대상에서 빠져 있던 것이 원인. 앞으로 새 설정이 추가돼도 자동으로 포함되도록 초기화 방식을 개선해 근본 해결
- 생산현황이 종합현황과 구성이 비슷해 보임 → 마지막까지 남아 있던 중복 구성(게이지·로그·주간 현황)을 생산 현장 전용 표현(안돈 현황판·불량 유형 분석·목표 달성 등)으로 교체해 차별화
- 차트 종류를 바꿀 때 값 표시(말풍선)가 겹쳐 뜨는 현상 → 기존 방식과 새 방식이 중복 동작하던 부분을 정리해 하나로 통일
- 실시간으로 변하는 차트에서 값이 이전 수치로 표시될 수 있음 → 마우스를 올린 순간의 최신 값을 읽어오도록 처리
- 단계 카드가 펼쳐질 때 카드마다 열리는 속도가 달라 보임 → 카드 크기에 따라 열리는 시간을 맞춰 일관된 속도로 조정
